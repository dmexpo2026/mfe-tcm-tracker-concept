Architecture

Built on Model Context Protocol

Two bundled MCP servers expose Polarion and DMS as structured tools — the agent orchestrates them with zero hard-coded logic.

Polarion MCP Server

Node.js server translating Copilot tool calls into Polarion REST API queries. Handles authentication, pagination, and field projection.

DMS MCP Server

Fetches CP HTML pages, parses state & branch info, resolves user emails. All internal DMS HTTP calls tunnelled through the server.

Automation Scripts (optional)

Python pipeline for CI/headless runs — bypasses the agent and generates dashboards fully unattended via env-var credentials.
